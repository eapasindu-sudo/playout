Live card
Name Duration Fixed start Live source Video device Audio device ATEM Mini: video "Blackmagic Design" and its sound device (picked by itself). Set the ATEM to the same frame rate as Playout (ATEM Software Control > Settings > Video standard 1080p25) or the picture judders. Phone Remote > Stream health shows what the device sends. Feed address SRT / RTMP with 0.0.0.0 = Playout waits for the sender (vMix, OBS, a phone app) to connect to this PC. Also: srt://other-pc:9000, rtsp://camera, .m3u8 (HLS) links, YouTube / Facebook live links. Main vMix input = the NDI source picked on the main screen. Plug in a USB / HDMI capture device (AverMedia, Elgato, Magewell...), press ⟳ and pick it here.

Backup PC (main / backup)
This PC is Main PC address Sync key Take over after seconds without the main PC Streams Files Status The backup copies the playlist, CGs and missing clips from the main PC and plays the same item at the same point, so vMix / the switcher can change to the backup's NDI output at any time.
